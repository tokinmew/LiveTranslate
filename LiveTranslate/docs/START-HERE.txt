LiveTranslate 0.7.1 for Windows 11 x64

This patch removes bright default Windows surfaces from app controls, using
subtle dark borders and scrollbars while keeping clear keyboard focus.

The sidebar opens Live session, Session history, Audio setup and Settings.
Choose your real audio input in Audio setup. Translation currently targets
English. Live session keeps screen watching, capture area, Read once,
pasted-text translation and reply practice available.

Pause translation remembers the running inputs. End session stops capture
and keeps the transcript. Save transcript writes a file only when you choose
one. History contains the newest 180 captions from this app session.
Open captions shows a separate pinnable Windows caption window.

For a new installation, open LiveTranslate-0.6.9-Setup.exe and choose Install.
Open LiveTranslate from the Start menu. You can also open LiveTranslate.exe
in the application folder. Guides and notices are in docs, maintenance
commands are in scripts, and model configuration is in config.

Under Translate text, choose Practice a reply for a separate pronunciation
guide. The starter examples work offline. Custom translations use the optional
multilingual written pack under Settings, Language files, Get more text languages.

For spoken translations, open Settings and Spoken English. Select an
installed English voice and an output device, then enable spoken playback.
For updates, open Settings, Updates and select Check for updates. Updates
come only from the official public GitHub Releases channel. No sign-in is
needed. Local manifests and old update-source preferences are ignored.
If GitHub is unavailable, the app reports that it could not check.

1. If you use the portable ZIP, extract it to a writable local folder
   with about 3 GB free. Inside LiveTranslate, double-click LiveTranslate.exe.
   First launch prepares and verifies the included runtime and models.
2. Choose a source language. Asian languages appear first. Traditional
   and Simplified Chinese, Japanese and Korean include screen and text models.
3. Watch screen translates words on the selected display. Choose Capture area
   to focus on a region. Turn on Auto listen for computer audio, microphone,
   or both. English is filtered before captions are displayed.
4. To add written languages, open Settings and choose Get more text
   languages. The optional checked model downloads 601 MiB and works locally.
   It is licensed for noncommercial use. Restart the dashboard after setup.
5. For PC VR, open VR captions. Select LiveTranslate VR captions in your
   headset's PC desktop/window view, then pin it if your runtime supports it.

See README.md for controls, VALIDATION.md for results and SOURCE-CHECKS.md
for antivirus and model-source details.
