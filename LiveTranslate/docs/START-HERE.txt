LiveTranslate 0.8.1 for Windows 11 x64

0.8.1 fixes manual capture when LiveTranslate covers the target. Read once
and Preview briefly reveal the background text, then restore the dashboard.
For Watch screen, minimize the dashboard or choose the application target.
Use text displayed in the browser/game, not LiveTranslate's own input box.

Preview is a direct button. Its Recognition details tab shows unverified OCR
and accepted source text separately. These are diagnostics, not captions.
Whole-scene icon safeguards also apply to explicitly selected Asian languages.
Repeated identical text flaps no longer flood the transcript.

Audio setup now shows measured input level and recognition decisions. Base
stays the default; the checked Small-only model download is optional, and Use
Small selects it explicitly. Model choice is remembered. Larger is not a
guarantee of better accuracy and can be slower on CPU.

VR captions now includes background opacity and per-connection saved layouts.
0% makes the background transparent; text stays opaque. Connection profiles
require SteamVR. OpenXR/VDXR and standalone overlay support remain unavailable.

This feature update adds native SteamVR captions, application capture and a
capture preview. Screen reading reports missing pixels or unconfirmed text.
Slower speech keeps more context across pauses and at phrase time limits.

The interface keeps subtle dark borders and scrollbars with clear keyboard
focus; the earlier capture-menu crash fixes are also retained.

The sidebar opens Live session, Session history, Audio setup and Settings.
Choose your real audio input in Audio setup. Translation currently targets
English. Live session keeps screen watching, capture area, Read once,
pasted-text translation and reply practice available.

Pause translation remembers the running inputs. End session stops capture
and keeps the transcript. Save transcript writes a file only when you choose
one. History contains the newest 180 captions from this app session.
Open captions offers desktop captions or native SteamVR captions.

Quest 3S / Virtual Desktop: launch VRChat through SteamVR. Open Settings,
VR captions, then Start VR captions. Adjust placement there. Minimize the
dashboard and return to VRChat; the native overlay does not require a second
monitor or a desktop window pinned to your wrist. VDXR/OpenXR and standalone
headset sessions do not have a supported native overlay yet.

Choose the VRChat application under Capture area, then Preview captured view
to verify the source. Keep VRChat restored and rendering. A window that cannot
provide pixels reports an error; it never silently falls back to the desktop.
This reads the application's PC view, not a direct headset framebuffer.

For German, Italian and Spanish text, choose that source language explicitly.
Settings, Language files, Get more text languages prepares the optional checked
multilingual text pack and their matching OCR files (about 607 MiB total).
Install these on each PC. The text model is for personal, noncommercial use.
Automatic screen reading currently covers Chinese, Korean and Japanese.

For a new installation, open LiveTranslate-0.6.9-Setup.exe and choose Install.
Open LiveTranslate from the Start menu. You can also open LiveTranslate.exe
in the application folder. Guides and notices are in docs, maintenance
commands are in scripts, and model configuration is in config.

Under Translate text, choose Practice a reply for a separate pronunciation
guide. The starter examples work offline. Custom translations use the optional
multilingual written pack under Settings, Language files, Get more text languages.

For spoken translations, open Settings and Spoken English. Select an
installed English voice and an output device, then enable spoken playback.
For updates, open Settings, Updates and select Check for updates. Updates
come only from the official public GitHub Releases channel. No sign-in is
needed. Local manifests and old update-source preferences are ignored.
If GitHub is unavailable, the app reports that it could not check.

1. If you use the portable ZIP, extract it to a writable local folder
   with about 3 GB free. Inside LiveTranslate, double-click LiveTranslate.exe.
   First launch prepares and verifies the included runtime and models.
2. Choose a source language. Asian languages appear first. Traditional
   and Simplified Chinese, Japanese and Korean include screen and text models.
3. Watch screen translates words on the selected display. Choose Capture area
   to focus on a region. Turn on Auto listen for computer audio, microphone,
   or both. English is filtered before captions are displayed.
4. To add written languages, open Settings and choose Get more text
   languages. The optional checked model downloads 601 MiB and works locally.
   It is licensed for noncommercial use. Restart the dashboard after setup.
5. For PC VR through SteamVR, start Native VR captions under Open captions.
   Select the VRChat application for OCR and confirm its captured preview.

See README.md for controls, VALIDATION.md for results and SOURCE-CHECKS.md
for antivirus and model-source details.
